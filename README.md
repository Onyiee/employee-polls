# Employee Polls

Employee Polls is a React application that allows users to create, answer and participate in Would You Rather polls. Users can explore unanswered and answered polls, view poll results and see how they rank on the leaderboard.

The project was built as part of the Udacity React Nanodegree programme, with a focus on React, Redux and application testing.

## Features

- **Authentication:** Log in using one of the available demo accounts.
- **Dashboard:** View unanswered and answered polls, organised by their creation dates.
- **Poll Details:** View poll options, submit an answer and see voting results.
- **Create Polls:** Create new polls with two answer options.
- **Leaderboard:** View users ranked by their participation and contributions.
- **Protected Routes:** Restrict access to authenticated pages.

## Getting Started

Follow these instructions to run the application locally.

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Onyiee/employee-polls
   ```

2. Navigate into the project directory:

   ```bash
   cd employee-polls
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run start
   ```

5. Open the local URL displayed in your terminal to access the application.
